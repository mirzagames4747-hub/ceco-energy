Description / Highlights / Datasheet are optional — if your Supabase products table doesn't have these columns yet, they'll just be skipped (nothing breaks). Ask your developer to run: ALTER TABLE products ADD COLUMN description text, ADD COLUMN highlights text, ADD COLUMN datasheet_url text; to enable them.

Display Order (and dragging rows in the table below) needs a sort_order column too — if it's missing you'll get a one-time notice instead of an error. Add it with: ALTER TABLE products ADD COLUMN sort_order integer;
